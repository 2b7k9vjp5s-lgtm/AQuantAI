# AQuantAI 中文新手操作指引

## 1. 启动

Windows 双击 `start-aquantai.bat`；macOS/Linux 运行 `./start-aquantai.sh`。浏览器打开 `http://127.0.0.1:8000/research-workspace`，确认页面显示“本地数据库已连接”。

直接使用 Python 时：

```bash
python -m scripts.init_v1_product
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

## 2. 创建研究案例

进入“研究案例”并点击“创建研究案例”。选择行业研究或公司研究，填写唯一案例标识键、标题、研究问题、研究者、信息截止日以及行业或公司信息。创建后记下详情页中的研究案例 ID。

## 3. 导入与审核 PDF

1. 打开“导入与审核队列”，选择本地官方 PDF。
2. 核对 SHA256、页数和逐页文本。
3. 用鼠标选中一段原文。
4. 填写研究案例 ID、文档标题、发布者、日期、事实陈述、来源类型、证据等级、审核人和审核备注。
5. 不采用时点击“拒绝所选证据”；采用时依次保存审核快照、生成预览、明确接受并写入。

重复文件不会生成重复 canonical 文档。扫描 PDF 无内嵌文本时会明确提示需要 OCR，不会补造文本。

## 4. 绑定证据并保存修订

返回研究案例详情，点击“保存新修订”，填写结构化研究内容和变化摘要，并勾选本案例的已接受证据。“已完成”或“已支持”的权威修订至少必须绑定一条已接受证据。

## 5. 查看与导出

- 在“证据账本”按已导入、待审核、已接受、已拒绝筛选。
- 在“研究变化”查看真实导入、接受和修订事件。
- 使用“搜索”查找案例、公司、行业、来源、证据或文档。
- 在案例详情导出 Markdown 或 HTML 报告；引用包含来源、文档、页码和证据 ID。

## 6. AI 研究助手

AI 是可选功能。未配置 AI 时核心流程完全可用。配置后必须先预览发送清单并逐次确认远程传输。AI 只能基于已接受证据生成临时草稿，不能接受或拒绝证据、修改 canonical Evidence、决定权威修订或执行交易。

## 7. 常见问题

- 页面打不开：访问 `http://127.0.0.1:8000/health` 检查服务。
- 数据库不可用：确认 PostgreSQL 已启动，并运行 `python -m alembic upgrade head`。
- 证据无法绑定：确认它已明确接受且属于同一个研究案例。
- 扫描件没有文字：V1 暂不提供 OCR，请使用包含可提取文本的 PDF。
- 系统边界：AQuantAI 仅用于本地研究和学习，不构成投资建议、推荐或交易指令。

AQuantAI 新手操作指引

建议第一次使用时按下面顺序操作。系统只用于本地研究，不会自动接受证据，也不会执行交易。

进入研究工作台打开导入与审核队列

一、确认系统已启动

  1. Windows 双击 start-aquantai.bat；macOS/Linux 运行 ./start-aquantai.sh。
  2. 浏览器打开 http://127.0.0.1:8000/research-workspace。
  3. 顶部显示“本地数据库已连接”后再开始操作。

二、创建研究案例

  1. 进入“研究案例”，点击“创建研究案例”。
  2. 选择“行业研究”或“公司研究”。
  3. 填写唯一的案例标识键、标题、研究问题、研究者和信息截止日。
  4. 提交后系统创建第 1 个草稿修订。案例 ID 会在详情页显示，后续审核 PDF 时需要它。

三、导入并审核 PDF

  1. 进入“导入与审核队列”，选择本地官方 PDF。
  2. 核对 SHA256、页数和逐页文本。重复文件不会创建重复 canonical 文档。
  3. 在逐页文本中用鼠标选中一段原文。
  4. 填写研究案例 ID、文档标题、发布者、日期、事实陈述、来源类型、证据等级和审核人。
  5. 不采用该证据时点击“拒绝所选证据”；采用时先保存审核快照，再生成预览，最后点击“明确接受并写入”。

扫描 PDF 没有内嵌文本时会提示“没有可提取文本，需要 OCR”。V1 不会伪造或猜测文本。

四、把证据绑定到研究修订

  1. 返回“研究案例”，打开刚才的案例。
  2. 点击“保存新修订”，填写研究内容和变化摘要。
  3. 在“绑定已接受证据”中勾选本案例的证据。
  4. 只有证据充分时才选择“已完成”和“已支持”；这类权威修订至少必须绑定一条已接受证据。
  5. 提交后可查看完整修订历史和证据引用。

五、查看、搜索与导出

  • “证据账本”可按已导入、待审核、已接受、已拒绝筛选。
  • “研究变化”显示真实文档导入、证据接受和研究修订事件。
  • “搜索”可查研究案例、公司、行业、来源、证据和文档。
  • 案例详情支持导出 Markdown 和 HTML，报告包含来源、文档、页码、证据 ID 与免责声明。

六、可选 AI 研究助手

未配置 AI 时全部核心功能仍可使用。配置后，必须先预览仅包含已接受证据的发送清单，再逐次确认远程传输。AI 输出只是临时草稿，不能审核证据、修改来源记录或决定权威修订。

常见问题

  • 页面打不开：先访问 /health，确认返回 {"status":"ok"}。
  • 数据库不可用：确认 PostgreSQL 已启动并执行 python -m alembic upgrade head。
  • 证据无法绑定：确认它已被明确接受，并且属于同一个研究案例。
  • 无法形成权威修订：“已完成”或“已支持”修订必须绑定已接受证据。
